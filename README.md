## 📖 About This Repository

This repository is a complete log of my Java training at **BridgeLabz**. It is organized into topic-specific branches, each containing hands-on problem sets, concept explorations, and real-world exercises — progressing from Java fundamentals all the way through to advanced topics like multithreading, design patterns, and test-driven development.

Each branch represents a dedicated learning module. The code follows clean naming conventions and is self-contained with comments explaining the logic.

## ☕ Setting Up Java (JDK/JRE/JVM)

### 🔍 Understanding JDK, JRE, and JVM

```
  Your Java Code (.java)
         ↓
  javac (JDK Compiler)
         ↓
  Bytecode (.class file)
         ↓
  JVM (Java Virtual Machine) — inside JRE
         ↓
  Machine Code (runs on your OS)
```

| Component | Full Form | Role |
|---|---|---|
| **JDK** | Java Development Kit | Contains compiler (`javac`), debugger, tools. You need this to **write & compile** Java |
| **JRE** | Java Runtime Environment | Contains JVM + libraries. You need this to **run** Java programs |
| **JVM** | Java Virtual Machine | Converts bytecode to machine code. Makes Java **platform-independent** |

> 💡 **Simple rule:** Install JDK — it includes JRE which includes JVM.

---

### 📥 Step-by-Step JDK Installation

**1. Download JDK**
- Go to: [https://www.oracle.com/java/technologies/downloads/](https://www.oracle.com/java/technologies/downloads/)
- Choose your OS (Windows / macOS / Linux) and download the latest JDK

**2. Install JDK**
- Run the installer and follow on-screen instructions
- Note the installation path (e.g., `C:\Program Files\Java\jdk-21`)

**3. Set Environment Variables**

**Windows:**
```
1. Search "Environment Variables" in Start Menu
2. Under System Variables → click "New"
   Variable name:  JAVA_HOME
   Variable value: C:\Program Files\Java\jdk-21
3. Find "Path" variable → Edit → Add:
   %JAVA_HOME%\bin
4. Click OK → Apply
```

**macOS / Linux:**
```bash
# Add to ~/.bashrc or ~/.zshrc
export JAVA_HOME=/usr/lib/jvm/java-21-openjdk
export PATH=$JAVA_HOME/bin:$PATH

# Apply changes
source ~/.bashrc
```

**4. Verify Installation**
```bash
java -version
javac -version
```
You should see the installed version number ✅

## ▶️ How to Run Java Files

```bash
# Step 1 — Navigate to the folder containing your .java file
cd path/to/your/folder

# Step 2 — Compile the Java file
javac FileName.java

# Step 3 — Run the compiled class (no .java extension!)
java FileName
```

**Example:**
```bash
cd Core_Programming/ControlFlow
javac WhileLoopDemo.java
java WhileLoopDemo
```

## 📤 GitHub — Push Your Code

### First-Time Setup
```bash
# Configure your identity
git config --global user.name "Dev Pratap Singh"
git config --global user.email "your-email@example.com"
```

### Standard Daily Workflow
```bash
# 1. Initialize Git (only once per project)
git init

# 2. Connect to your GitHub repository
git remote add origin https://github.com/devps814/BridgeLabz-Training-Java-Programming.git

# 3. Check which branch you're on
git branch

# 4. Switch to / create your working branch
git checkout -b Core_Programming
# or switch to existing branch
git checkout Core_Programming

# 5. Check what files were changed
git status

# 6. Stage all changes
git add .

# 7. Commit with a meaningful message
git commit -m "Add control flow exercises — loops and conditionals"

# 8. Push to GitHub
git push -u origin Core_Programming
```

### Other Useful Commands
```bash
# Pull latest changes from remote
git pull origin Core_Programming

# See commit history
git log --oneline

# See difference in changed files
git diff

# Undo last commit (keeps changes)
git reset --soft HEAD~1

# List all branches
git branch -a
```
